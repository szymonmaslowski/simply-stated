# Documentation site

Astro + [Starlight](https://starlight.astro.build) site for Simply Stated.

It owns **no prose of its own**. `scripts/sync-docs.mjs` mirrors the markdown
that already lives in the repository (root `README.md`, `API_REFERENCE.md`, the
package and example READMEs) into `src/content/docs`, adds the frontmatter
Starlight needs, and rewrites every relative link to the page it became. Every
`.ts` file under `examples/` also gets a syntax-highlighted page, so prose can
link to the code it discusses without leaving the site.

`src/content/docs` is generated and git-ignored. **Edit the source markdown in
the repository, not the copies here.**

## Commands

```bash
pnpm dev      # sync + watch sources, run the dev server
pnpm sync     # one-off sync
pnpm build    # sync, then build the static site into dist/
pnpm preview  # serve the built site
pnpm check    # sync, then astro check
```

## Adding a document

Add an entry to `markdownPages` in `scripts/docs-sources.mjs` (source path,
route, sidebar order) and, unless the route is picked up by an autogenerated
group, add it to `sidebar` in the same file.

## Deployment

`DOCS_SITE` and `DOCS_BASE` set the deployed origin and path prefix (`DOCS_BASE`
is needed for GitHub project pages, e.g. `/simply-stated`); `DOCS_SOURCE_REF`
sets the git ref that GitHub links point at (defaults to `main`).
